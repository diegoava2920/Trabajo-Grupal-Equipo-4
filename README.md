## Descripción del proyecto

TechEvents CR es una página web donde se muestran eventos de tecnología en Costa Rica.

En la página se puede ver la información de cada evento, como la fecha, la modalidad y los cupos disponibles. También permite realizar inscripciones y llevar un control de los cupos.

## Tecnologías utilizadas

- **HTML:** para crear la estructura de la página.
- **CSS:** para los colores, las tarjetas y el diseño.
- **JavaScript:** para mostrar los eventos, manejar los botones y controlar las inscripciones.
- **GitHub:** para trabajar en equipo, guardar los cambios y revisar los Pull Requests.
